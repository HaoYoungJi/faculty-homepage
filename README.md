# 中文学术与教学主页

打开 `index.html` 即可在浏览器查看。网页可直接用于 GitHub Pages，支持手机与电脑；访问量数字由外部统计服务提供。

页面右上角提供中英文切换、深浅主题切换，以及打印或保存为 PDF。选择会保存在当前浏览器中。页面滚动后会出现返回顶部按钮，导航栏也会提示当前所在栏目。课程页支持按日期、主题或讲次筛选课程表。

## 填写个人内容

用文本编辑器打开 `index.html`，将“你的姓名”“待填写”等占位文字替换为个人资料。论文和课程条目都是占位内容，不是真实成果。填写完成后，删除带有 `class="draft-note"` 的提示行。

添加照片时，将照片放在同一文件夹，例如 `photo.jpg`，并将 `<div class="portrait">…</div>` 替换为：

```html
<img src="photo.jpg" alt="你的姓名的个人照片" class="portrait" style="object-fit:cover;display:block">
```

要添加课程资料，将 PDF 放入自己创建的 `files` 文件夹，再把相应的占位内容改为链接，例如：

```html
<a href="files/syllabus.pdf">教学大纲（PDF）</a>
```

## 发布到 GitHub Pages

本项目使用 `HaoYoungJi/faculty-homepage` 仓库。推送到 `main` 分支后，进入 `Settings → Pages`，选择 `Deploy from a branch`，再选 `main` 与 `/(root)` 并保存。部署完成后，网页地址为 `https://haoyoungji.github.io/faculty-homepage/`。

## 课程详情页

首页的两个课程条目分别链接到 `course-01.html` 与 `course-02.html`。修改对应文件即可更新课程简介、教学安排和资料区。资料尚未上传时只显示状态；准备好文件后，可将对应名称改为指向资料的链接。三个 HTML 文件与 `style.css` 应放在仓库同一层。

## 中英文信息、主题与访问量

主页的个人资料、课程名称和课程详情已经加入英文对照占位文字。带有 `data-zh` 与 `data-en` 的标题可通过顶部按钮切换语言；替换内容时请同步修改这两个属性中的文字。

页面底部使用不蒜子统计服务显示访问量。上传到 GitHub Pages 后会按网站域名累计；本地预览显示的数字不代表正式网站访问量。访问者禁用网页脚本或统计服务暂时不可用时，数字会保留为“—”。

## 当前版式

首页以传统高校教师主页为结构参考，采用左侧照片、右侧姓名与联系信息，并在下方直接列出简历、科研、教学和相关链接。主页内容仍是占位文字，未使用参考网站作者的姓名、照片或个人经历。

课程页包含课程公告、课程信息，以及“序号、日期、内容、讲义、作业”五列教学进度表。每次课的讲义可以分别上传，学期末也可以提供完整合集。要增加讲次，复制表格中的一个 `<tr>...</tr>` 条目并修改内容即可。
