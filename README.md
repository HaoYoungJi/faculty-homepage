# 吉浩洋的学术与教学主页

公开网址：<https://haoyoungji.github.io/faculty-homepage/>

主页内容在 `index.html` 中维护；样式在 `style.css` 中维护。`course-01.html` 是当前课程的待填写页面，`course-02.html` 是数学分析习题课，`course-03.html` 是微积分(A)。课程讲义位于 `files/`，个人照片为 `portrait.jpg`。

数学分析习题课使用一份跨 2023–2024、2024–2025、2025–2026 学年的通用讲义。`files/math-analysis/` 中保留原始完整 PDF，同时按原文件目录拆为 13 个章节 PDF；第一章文件也包含封面和目录。课程页只列出一组共用链接，避免按学年重复。

微积分(A)现存资料位于 `files/calculus-a/`。较大的 PDF 按原文件页码分卷，分卷位置不代表章节边界。

网站使用 GitHub Pages，从 `main` 分支的仓库根目录发布。网页提供中英文切换、深浅主题切换、打印、返回顶部，以及由不蒜子提供的访问量统计。修改课程文件或 `files/` 下的资料后，提交并推送到 `main`，GitHub Pages 会更新公开网页。
